# 科技股日报 2026年3月20日

> 聚焦阿里巴巴、美团、小米三大科技巨头最新动态

## 阿里巴巴 (BABA/09988.HK)

### 核心看点
- **AI+云战略升级**：蔡崇信、吴泳铭明确表示未来十年最大增量来自AI驱动力
- **云业务爆发**：阿里云财年收入突破双位数增长，AI相关产品收入连续**七个季度**三位数同比增长
- **通义开源**：Qwen3模型性能领先全球，开源200余款模型，衍生模型超10万个

### 关键数据
- 2025财年收入：9963.47亿元
- 净利润：同比增长77%至1259.76亿元
- 阿里云服务：约63%的A股上市公司

- 88VIP会员规模超**5000万**
- 夸克月活突破**2亿**
