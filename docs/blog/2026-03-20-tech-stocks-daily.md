# 科技股日报 2026年3月20日

## 阿里巴巴 (BABA)

### 财报要点

阿里巴巴发布2026财年Q3财报（截至2025年12月31日）：

- **收入**：2848.43亿元，同比增长2%（同口径增长9%）
- **阿里云**：收入增长36%，AI相关产品收入连续第十个季度三位数增长
- **净利润**：非公认会计准则净利润167.10亿元，同比下降67%
- **经营利润**：106.45亿元，同比下降74%

### 业务进展

- **即时零售**：饿了么品牌更新为"淘宝闪购"，于2026年1月15日接入千问App
- **88VIP会员**：数量已超5900万
- **国际业务**：亏损同比大幅收窄，速卖通Choice单位经济效益环比持续改善

### 人事变动

千问核心负责人林俊旸离职，CEO吴泳铭回应：技术发展不进则退，将持续吸纳优秀人才。公司已成立基础模型支持小组，由CEO直接协调资源。

### 架构升级

6月8日，阿里巴巴宣布合并通义大模型事业部和未来生活实验室，成立Token Foundry事业部，由CEO吴泳铭直接负责。周靖人担任首席科学家，牵头成立阿里巴巴AI未来研究院。

## 美团 (03690.HK)

### 一季度业绩

- **营收**：910亿元，同比增长5.6%
- **经营利润**：由盈利106亿元转为亏损65亿元
- **净亏损**：68亿元

### 业务数据

- **核心本地商业**：收入641亿元，同比微增0.1%，经营利润由135亿元盈利转为20亿元亏损
- **新业务**：收入270亿元，同比增长21.3%，亏损从23亿元收窄至21亿元
- **销售及营销开支**：同比激增51.1%至230亿元，占收入比重从17.6%升至25.2%
- **监管罚款**：市场监管总局就商家资质审查合规缺陷处以7.46亿元罚款

### AI布局

美团加速AI布局，推出智能助手"小囝"及商家端AI工具，覆盖超70万餐饮商户。
