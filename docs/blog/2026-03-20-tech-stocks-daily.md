# 每日科技股分析 2026-03-20

## 阿里巴巴 (BABA)

### 派息与AI业务进展
阿里巴巴宣布派息25亿美元，AI业务目标年底ARR破300亿。董事会已批准派发2026财年年度现金股息，总额约25亿美元，派息对象为2026年6月登记股东。

### ESG报告发布
阿里巴巴集团发布2026财年ESG报告，显示AI正成为ESG行动的"效率杠杆"和"价值杠杆"。过去一年，阿里巴巴自身运营减排量达319.5万吨。

## 美团 (3690.HK)

### Q1财报要点
美团2026年第一季度营收910.4亿元，同比增长5.6%；期内亏损68.3亿元。配送服务收入250.1亿元。

### 战略转折点
美团正处于从"补贴换份额"到"效率换利润"的战略转折点。2025年为应对外卖行业"内卷式"竞争，公司由盈转巨亏。但2026年一季度已确认减亏拐点。

### 股东周年大会
美团将于2026年6月26日召开股东周年大会，审议董事选举及股份购回授权。

### 机构观点
大和料美团利润率很有可能已经见底，重申"买入"评级。
